I'm a Software Engineer and the Technical Lead and Co-founder of [Fair Assistant](https://fairassistant.com), a business card scanner for trade show exhibitors that is live on Google Play. Before that I spent four years at Euronet Worldwide working on the [XE](https://www.xe.com/) and Ria Money Transfer web platforms.

I care about software that holds up in production: strict typing, clear architecture and tests that catch problems before users do.

### 👨🏻‍💻 &nbsp;About Me

💡 &nbsp;At Euronet I was one of the main developers on XE's migration from Vue 2 and Vuex to Vue 3, Pinia and TypeScript, in a team of 10.\
🚀 &nbsp;At Fair Assistant I built a Nuxt 4 team dashboard, a Nuxt SSR website in 22 languages and a Node.js, Fastify and PostgreSQL API in production.\
🤖 &nbsp;I work with LLMs in real features (Gemini structured output for reading business cards) and run development through Claude Code agents with specs, review and tests.\
🎓 &nbsp;BSc in Computer Science and Software Engineering, Faculty of Technical Sciences Čačak.\
📍 &nbsp;Based in Belgrade, Serbia. Open to remote roles across Europe.\
